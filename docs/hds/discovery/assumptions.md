# Assumptions

## Registro inicial

Este arquivo registra premissas assumidas no bootstrap. O agente deve manter este documento atualizado, objetivo e não raso. Premissas não são fatos; elas precisam ser validadas quando afetarem arquitetura, prazo, budget, segurança, escopo, dados, integrações, usuários ou operação.

## Validação

Toda premissa crítica deve ter owner, origem, impacto e plano de confirmação. Quando a premissa for confirmada, mova a decisão para `AGENT_DECISIONS.md` ou para um ADR. Quando a premissa for inválida, registre impacto e ação corretiva.
