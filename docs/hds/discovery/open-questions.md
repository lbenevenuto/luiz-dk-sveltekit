# Open Questions

## Registro inicial

Este arquivo concentra dúvidas que impedem decisões confiáveis. O agente não deve preencher lacunas com opinião ou invenção. Quando uma pergunta afetar segurança, dados, integração, arquitetura, prazo ou custo, ela deve ser tratada como bloqueio até resposta humana ou evidência confiável.

## Validação

Cada pergunta deve ter contexto, impacto, prioridade e possível caminho de resolução. Perguntas resolvidas devem ser movidas para decisões ou documentação adequada.
