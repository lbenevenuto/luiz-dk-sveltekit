# Finalidade

Estabelecer como a documentação deve ser criada, revisada, versionada, aprovada e preservada dentro do hDS.

# Regras principais

- documento vivo precisa de `owner` claro;
- documento vivo precisa de versão;
- documento vivo precisa de audiência definida;
- regras de negócio exigem documentação pareada para humano e IA;
- material legado deve ser preservado;
- alterações relevantes devem passar por revisão.

# Resultado esperado

A organização ganha memória operacional confiável, melhor governança e capacidade de usar IA com menos ambiguidade e menos risco.
