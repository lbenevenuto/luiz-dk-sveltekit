# Migration Policy

Ao migrar um projeto existente para hDS:

1. preservar documentação anterior em `legacy-documentation/`;
2. criar documentação corrente no padrão hDS;
3. indicar vínculo entre novo e legado quando necessário;
4. evitar copiar ruído histórico sem curadoria;
5. separar claramente o que é histórico do que é vigente.
